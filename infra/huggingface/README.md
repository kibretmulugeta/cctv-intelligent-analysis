# CCTV Intelligent Analysis & Face Recognition (Hugging Face Space)

Deploy to Hugging Face Spaces using the Docker SDK:

1. Create a new Space on [Hugging Face Spaces](https://huggingface.co/new-space).
2. Choose **Docker** as the SDK.
3. Push the `/backend` directory along with `infra/huggingface/app.py`.
4. The space will run on port `7860`.
